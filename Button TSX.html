Button TSX

Botão único das cinco frentes do Grupo TSX. Oito tipos, dois estados (Default e Hover). A cor da barra lateral, do hover do Default e do Light e dos links vem do accent, que muda com a frente.

Interação · Type Default e Light

A barra lateral vira o fundo

No repouso, os dois tipos mostram uma barra accent de 4 px na borda esquerda: o Default sobre bg-button-default, o Light sobre branco. No hover, essa barra cresce da esquerda para a direita até cobrir o botão inteiro e se torna o fundo sólido do estado Hover. Ao sair, ela recolhe de volta para a esquerda no mesmo tempo. No Default, rótulo e seta continuam brancos. No Light, eles passam de text-heading para branco no mesmo ritmo da barra, e os dois tipos terminam no mesmo estado Hover.

Implementação

CSS do Default e do Light

A barra é um ::before do tamanho do botão, recortado com clip-path para mostrar só 4 px. No hover o recorte abre por inteiro. Como só clip-path anima, a transição roda na GPU e o texto não se move.

.tb--default, .tb--light {
  /* tokens */
  --tb-dur: 420ms;
  --tb-ease: cubic-bezier(.65, 0, .35, 1);

  position: relative;
  isolation: isolate;          /* a barra fica entre o fundo e o texto */
  display: inline-flex;
  align-items: center;
  gap: 8px;
  height: 45px;
  padding: 0 16px 0 20px;     /* 16 + 4 da barra */
  border-radius: 2px;
  overflow: hidden;
  font: 400 18px/1 "Plus Jakarta Sans", sans-serif;
}

.tb--default {
  background: var(--bg-button-default);
  color: var(--text-button);
}

.tb--light {
  background: var(--text-button);
  color: var(--text-heading);
  transition: color var(--tb-dur) var(--tb-ease);
}
.tb--light:hover,
.tb--light:focus-visible {
  color: var(--text-button);        /* rótulo e seta (currentColor) */
}

.tb--default::before,
.tb--light::before {
  content: "";
  position: absolute;
  inset: 0;
  z-index: -1;
  background: var(--accent);
  clip-path: inset(0 calc(100% - 4px) 0 0);   /* repouso: 4px */
  transition: clip-path var(--tb-dur) var(--tb-ease);
}

.tb--default:hover::before,
.tb--default:focus-visible::before,
.tb--light:hover::before,
.tb--light:focus-visible::before {
  clip-path: inset(0 0 0 0);                  /* hover: 100% */
}

@media (prefers-reduced-motion: reduce) {
  .tb--light,
  .tb--default::before,
  .tb--light::before { transition: none; }
}
Notas

Pontos para revisar no Figma

Motion

O protótipo troca de estado sem transição

As interações "On hover → Change to" do component set não têm animação definida. Os 420 ms e a curva desta página são a proposta para o código; vale registrar no Figma (Smart Animate ou anotação) para dev e design ficarem iguais.

Variante

Hover do Light no Figma está diferente

No Figma, "Type=Light, State=Hover" ainda tem fundo bg #F2F2F2, barra de 4 px e rótulo escuro. Nesta folha ele passou a ter fundo accent e rótulo e seta em text-button, igual ao hover do Default. Atualize a variante no Figma para os dois baterem.

Nome

Underline passa a se chamar Ghost

Nesta folha, os tipos Underline, Underline Acent e Underline Light viraram Ghost, Ghost Acent e Ghost Light. O nome antigo não fazia sentido porque eles não têm sublinhado (traço de 0 px). No Figma as variantes ainda usam "Underline".

Variante

Nome duplicado no Icon Only light

O hover do Icon Only light se chama "Type=Icon Only, State=Hover", igual ao do Icon Only. Isso quebra as propriedades do set. Renomear para "Type=Icon Only light, State=Hover".

Contraste

Accent do Group sobre fundo escuro

No modo Group, o accent #005073 fica com contraste baixo sobre bg-inverse. Afeta a barra do Light em repouso e o hover do Ghost Light. Troque a frente para Group no topo para ver.

Token

bg-button-hover e stroke-button sem uso

As variáveis #004666 e #0075A8 existem, mas nenhuma variante do Button TSX usa mais. O .btn atual do index.html ainda usa o hover azul antigo.
